# MUDST Jersey — Web Prototype

ต้นแบบเว็บแอปพลิเคชัน E-Commerce สำหรับสั่งจองเสื้อเจอร์ซี่ MUDST (Digital Science & Technology, คณะ ICT มหาวิทยาลัยมหิดล)
จัดทำสำหรับรายวิชา ITDS294 Fundamental of Electronic Commerce System

## เปิดดู
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที (ไฟล์เดียว รวมรูปไว้ในตัวแล้ว) หรือเปิดผ่าน GitHub Pages

## ฟีเจอร์
**หน้าร้าน (ลูกค้า)**
- หน้ารวมสินค้า 12 ช่อง (เสื้อจริง 2 แบบ + ช่องจำลองสำหรับแบบในอนาคต)
- หน้าสินค้า: รูปหน้า/หลัง ตารางไซซ์ ตัวช่วยเลือกไซซ์ สกรีนชื่อและเบอร์ด้านหลังพร้อมตัวอย่างสด
- ตะกร้า ชำระเงิน (พร้อมเพย์/โอน + แนบสลิป) และติดตามสถานะคำสั่งซื้อ
- โหมดกลางวัน/กลางคืน รองรับมือถือ

**หลังบ้าน (ผู้ดูแล)**
- ภาพรวมยอดขายเทียบจุดคุ้มทุน 49 ตัว / เป้า 100 ตัว
- ตรวจสลิป เปลี่ยนสถานะ ใส่เลขพัสดุ
- สรุปยอดผลิตแยกแบบ × ไซซ์ และรายการสกรีนชื่อ-เบอร์ คัดลอกส่งโรงงานได้
- จัดการแบบเสื้อและตั้งค่ารอบขาย

> ข้อมูลทั้งหมดเป็นข้อมูลจำลอง รีเฟรชแล้วจะเริ่มใหม่ QR และเลขบัญชีเป็นตัวอย่าง ใช้จ่ายจริงไม่ได้

## โครงสร้างไฟล์
- `index.html` ไฟล์ที่ใช้เปิดดู (build แล้ว)
- `src.html` ซอร์สโค้ด (ยังไม่ฝังรูป)
- `build.py` ฝังรูปจาก `img/` ลงใน `src.html` แล้วเขียนเป็น `index.html` (`python3 build.py`, ต้องมี Pillow)
- `img/` รูปเสื้อที่ใช้ในเว็บ
- `assets/` รูปเสื้อพื้นใสความละเอียดเต็ม
